## Backend (Product API)

- Удалены `User` / `UserAccess` / `UserRole`, EF-конфиги, `UserService`, `AuthController`, `UsersController`, локальный `JwtTokenService`.
- `Order` / `WishlistItem`: только `UserId` без FK на Users.
- Миграция `DropUserTables`.
- `OrderService` / reviews / stock-notify / admin orders — без `_db.Users`; имя из JWT claims.
- JWT: конфиг под внешний Auth (`Jwt:*`, `AuthService:BaseUrl`); helper `AuthClaims`.
- Razor `Perry.Web` account/users — stubs (источник правды: Auth + React).

## Frontend

- `VITE_AUTH_API_URL` → Perry Auth Service.
- `authApi` / `usersApi` на Auth; Product API только каталог/корзина/заказы с Bearer.
