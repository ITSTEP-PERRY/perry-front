## Что сделано

### Frontend (`perry-front`)
- `AccountShell` — сайдбар (аватар, роль, My orders / Wishlist / Account settings), breadcrumbs `/ Account`
- Маршруты: `/account/orders`, `/account/wishlist`, `/account/settings` (редиректы со старых `/profile`, `/orders`)
- **Wishlist** — сетка карточек, поиск, Remove + confirm modal; `WishlistContext` + API
- **My orders** — список со статусами (Ordered / Received / Shipped / Ready for pickup / Cancelled), модалка Details
- **Account settings** — модалки:
  - Change name (First / Last)
  - Change password (current + new + repeat, валидации, eye)
  - Change email (новый email + пароль + OTP 6 цифр, Send code / Resend)
  - Log out? / Delete account?
- PDP: «Add to wish list» пишет в API
- Header: ссылки на account / wishlist

### Backend (`Perry.Api`)
- `WishlistController` — `GET/POST/DELETE /api/wishlist`
- Entity `WishlistItem` + миграция `AddWishlistAndOrderShipping`
- Заказы: поля `RecipientName`, `ShippingAddress`, `PaymentType`; в ответе — image позиций
- Auth:
  - `PUT /api/auth/me` — name / avatar
  - `PUT /api/auth/me/password` — сильный пароль (8+, upper/lower/digit)
  - `POST /api/auth/me/email/send-code` + `PUT /api/auth/me/email` — смена email по паролю + OTP
  - `DELETE /api/auth/me` — soft-delete
