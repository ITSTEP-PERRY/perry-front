# Свести две линии фронта (коротко)

На `main` perry-front сейчас **две линии кода**:

1. **Рабочая (Figma-порт)** — вход через `src/App.tsx` → `src/app/router.tsx`, стили `src/styles/*`, страницы `src/pages/*.tsx` + `admin/` + `account/` + `auth/`. Это то, что крутится при `npm run dev` и что в README со скринами спринта.
2. **Линия команды (Ant Design / Redux)** — `src/pages/HomePage/`, `CategoryPage/`, `Components/`, `app/store.ts`, `widgets/Header` и т.п. После merge лежит рядом, но **роутер на неё не смотрит**.

Задача кого-то из команды: оставить одну линию, без «двух домов».

## Что сделать

1. **Решить источник правды**  
   Рекомендация к защите: оставить **Figma-порт** (уже связан с API, админкой, Account, скринами). Линию Ant/Redux — архив или удалить.

2. **Проверить запуск**  
   `npm install` → `npm run dev` → `:3000`  
   API рядом: Perry.Api `:5272`. Smoke: Home, каталог, PDP, login, `/admin`, `/account`.

3. **Убрать мёртвый код линии 2** (если выбрали Figma)  
   Кандидаты: `src/pages/HomePage/`, `CartPage/`, `CategoryPage/`, `ProductPage/`, `SearchPage/`, `NotFoundPage/` (папки со своим `HomePage.tsx` и т.д.), `src/Components/`, `src/app/store.ts`, `slices/`, `api/apiSlice.ts`, дубли `widgets/Header|Footer|Hero…`, лишние deps в `package.json` (`antd` / `redux`, если больше нигде не нужны).  
   Не трогать: `src/pages/HomePage.tsx`, `ProductPage.tsx`, `admin/*`, `account/*`, `app/router.tsx`, `styles/*`.

4. **Или наоборот** — если берут линию Ant: переписать `App`/`main` на их роуты и **перенести** с Figma-порта: Account, Admin, API-клиент, скрины/docs. Это дольше.

5. **Закоммитить в `main`**, прогнать build (`npm run build`), коротко написать в чат: «оставили Figma / Ant, удалили …».

Backend (`My_Amazon2` / Back_end) уже на `main` со спринтом — **сводить не нужно**, только фронт.
