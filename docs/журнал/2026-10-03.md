---

## 1. Регистрация аккаунта (Auth multi-step)

**Проблема:** Create account не доводил пользователя до JWT — не хватало `confirmPassword` и шагов verify / complete.

**Сделано:**
- Desktop + Mobile: `register` → `verify-email` / код → `complete-registration` → `login`
- Понятные тексты ошибок Auth (`errors.*`)
- Коммит: `3064a89` — `fix(auth): complete multi-step account registration against Auth Service`

---

## 2. Обрезка цены на карточках каталога

**Проблема:** на широких экранах цена обрезалась (пропадала точка / дробная часть, например `$129.99` → визуально «битая»).

**Сделано:** CSS/layout карточки товара — цена не клипится на wide desktop.  
Коммит: `c21c917` — `fix(storefront): stop clipping product card prices on wide screens`

---

## 3. Отзывы: UUID вместо имени и ложный «Admin required»

**Проблемы:**
1. В карточке отзыва `AuthorName` = JWT `sub` (GUID), а не отображаемое имя.
2. При 401 Product API фронт показывал текст про Admin — обычный User думал, что отзывы только для админа.

**Сделано:**
- Backend / claims: имя автора не из сырого `sub`
- Клиент: корректные сообщения 401; отзывы доступны роли User
- Коммит: `2f908ae` — `fix(reviews): show author names and allow regular users to review`

## 4. Пакет vibe-prompts (документация + сценарий)

Папка [`vibe-prompts/`](../../vibe-prompts/README.md) в корне `perry-front`:

| Что | Зачем |
|-----|--------|
| `00` … `12` + `99` | Пошаговые промпты: видение → API → витрина → mobile → smoke |
| `PITFALLS.md` | Грабли дизайна и стыков (цены, Auth, reviews, pads, footer) |
| `AGENTS-AND-SEQUENCE.md` | Сколько агентов и порядок фаз |
| `HOW-TO-RUN-SEQUENCE.md` | Как гонять сценарий |
| `run-vibe-sequence.cmd` / `.ps1` | Копирует промпты в буфер по очереди (Enter / S / Q, state-файл) |

Старт сценария: двойной клик `vibe-prompts/run-vibe-sequence.cmd` или см. [HOW-TO-RUN-SEQUENCE.md](../../vibe-prompts/HOW-TO-RUN-SEQUENCE.md).
