## 8. Ограничения / риски

- Cookie JWT **не** httpOnly (читается JS) — XSS всё ещё опасен; для httpOnly нужен Auth.
- Seed-пул по умолчанию = 2 известных Auth Guid; больше пользователей — через `Seed__KnownUserIds`.
- Секреты SMTP в git/чат не попадали.
- Прямые URL `/products/...` на SWA без `navigationFallback` всё ещё могут давать 404 Azure (отдельно от аватара).
